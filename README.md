# Rangley 

Rangley is a location-based social meetup iOS app that connects users with events and activities happening nearby. Discover local happenings, create your own meetups, and expand your social circle with Rangley.

## Features

- Explore events and activities near your location
- Create and host your own meetups 
- Connect with friends and meet new people
- Customizable user profiles 
- Privacy controls and secure authentication

## Tech Stack

- Swift/SwiftUI for iOS client
- Vapor backend framework 
- PostgreSQL database
- AWS infrastructure (EC2, S3, Cognito)
- MapKit
